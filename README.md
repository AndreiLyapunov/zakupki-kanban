# Система управления закупками по проектам (`zakupki-kanban`)

Локальное веб-приложение на Python (Flask + SQLite) для ведения полного цикла закупок предприятия: от формирования заявки по проекту и сравнения счетов поставщиков до контроля оплаты, отслеживания доставки на канбан-доске, фиксации приёмки товара и архивации завершённых проектов.

Приложение работает полностью автономно на локальном компьютере без облачных серверов и платных подписок, а все базы данных, резервные копии и оригиналы счетов хранятся локально на диске.

## Основные возможности

1. **Проекты и сравнение счетов (Вкладка 1):**
   * **Компактный интерфейс и цветовая индикация проектов:** список активных проектов в левой панели с датой создания и живыми счётчиками этапов. Карточки автоматически подсвечиваются по статусу: **жёлтый** — новый формируемый проект, **голубой** — есть позиции в работе/доставке, **зелёный** — проект полностью получен.
   * **Привязка к папкам без дублирования:** выбор рабочей директории на диске через диалоговое окно (`zenity`), отображение всех файлов проекта под его заголовком и привязка счетов из папки к столбцам поставщиков без создания лишних копий.
   * **Импорт готовых таблиц сравнения:** загрузка сводных таблиц в любых форматах (**`.xlsx`**, **`.xlsm`**, **`.xls`**, **`.ods`**) с автоматическим извлечением цен (включая очистку от ГОСТов и диаметров) и примечаний.
   * **Распознавание счетов и сканов (OCR):** загрузка PDF, Excel, LibreOffice Calc и фотографий счетов. Автоматическое чтение текстового слоя и распознавание отсканированных PDF/изображений на русском и английском языках (`Tesseract OCR`) с автоподстановкой поставщика, номера счёта, цен позиций, резки и доставки.
   * **Полное редактирование на месте:** возможность изменять название и папку проекта, добавлять, редактировать или удалять строки материалов, править шапки счетов, заполнять пустые ячейки (`+ цена`), корректировать цены, вес, метры, стоимость доставки и примечания с мгновенным сохранением и зелёным уведомлением.
   * **Встроенный калькулятор НДС (+20% / +22%):** быстрый пересчёт цен, указанных без налога.
   * **Умная цветовая подсветка цен в таблице:**
     * **Светло-зелёный** — самая дешёвая (минимальная) общая цена за позицию.
     * **Светло-голубой** — позиция дороже минимальной (например, отгрузка целым хлыстом), но выгоднее в пересчёте за **1 метр** или **1 кг**.
     * **Светло-розовый** — самая высокая цена среди предложений.
   * **Удобная навигация и сквозное выделение строк:** закреплённый первый столбец материалов, закреплённая шапка поставщиков, постоянный горизонтальный бегунок, выбор отдельных позиций или **всего счёта целиком** одной кнопкой, а также подсветка выбранной строки на всю ширину таблицы при клике (включая нижние итоговые строки).
2. **Канбан-доска отслеживания счетов (Вкладка 2):**
   * **Фильтрация по проектам и группировка по счетам:** левая панель для отбора по конкретному проекту в работе; каждая карточка представляет конкретный счёт поставщика с указанием количества позиций и общей суммы.
   * **Этапы движения:** перемещение карточек между колонками кнопками быстрого перевода (**«➡ Оплачено»**, **«➡ В пути»**, **«➡ Прибыло»**, **«◀»**) или перетаскиванием мышкой.
   * **Логистика и контроль сроков:** учёт транспортной компании (ТК), трек-номера и плановой даты прибытия на весь счёт (просроченные поставки автоматически выделяются красной рамкой).
   * **Приёмка в один клик:** открытие файла счёта прямо из карточки и перевод всего счёта в полученные с выбором одного из **7 цветов** маркировки.

3. **Реестр полученных товаров (Вкладка 3):**
   * **Двухуровневый просмотр:** в левой колонке отображается список полученных проектов и счетов (окрашенных цветом приёмки), а в правой области раскрывается подробный состав принятых позиций с весом, метрами и ценой.
   * **Гибкая цветовая маркировка и архивация:** смена цвета как для всего полученного счёта целиком, так и для каждой отдельной позиции, а также кнопка **«📦 Проект в архив»** для отправки исполненного проекта в архив.

4. **Архив проектов (Вкладка 4):**
   * **Очистка рабочего пространства:** перенос исполненных проектов из активного списка в архив (с возможностью вернуть проект обратно в любой момент).
   * **Чистая история закупок:** при открытии архивного проекта в сводной таблице отображаются **только оплаченные счета**, без лишних коммерческих предложений.

5. **Надёжность и резервное копирование:**
   * Автоматическое создание резервных копий базы данных (`backups/zakupki_startup_*.db`) при запуске приложения (хранятся 3 самые свежие копии).
   * Кнопки в верхней панели: **«💾 Бэкап базы»** (мгновенный снимок базы данных) и **«📦 Бэкап программы»** (полный ZIP-архив с кодом приложения и базой данных; хранятся 3 последних архива).
   * Подробное логирование событий сервера и клиентских ошибок в `debug.log`.

## Технологии

* **Backend:** Python 3, Flask, SQLite3
* **Парсинг документов, таблиц и OCR:** `pdfplumber`, `pytesseract`, `pdf2image`, `Pillow`, `openpyxl`, `xlrd`, `odfpy`
* **Системные утилиты (Linux):** `zenity`, `tesseract-ocr` (`tesseract-ocr-rus`), `poppler-utils`
* **Frontend:** HTML5, CSS3, Vanilla JavaScript (`static/main.js`, без внешних фреймворков)

## Установка и запуск (Linux Mint / Ubuntu)

1. Установите системные пакеты для диалоговых окон и OCR-распознавания сканов:
   ```bash
   sudo apt update
   sudo apt install -y zenity tesseract-ocr tesseract-ocr-rus poppler-utils
   ```

2. Создайте виртуальное окружение и установите Python-зависимости:
   ```bash
   python3 -m venv venv
   source venv/bin/activate
   pip install flask pdfplumber pytesseract pdf2image pillow openpyxl xlrd odfpy
   ```

3. **Запуск через скрипт-переключатель (рекомендуется):**
   Используйте скрипт `toggle_zakupki.sh` (или ярлык на рабочем столе):
   * Первый запуск включает сервер в фоне и выводит системное окно-индикатор с адресом **`http://127.0.0`**.
   * Повторный запуск останавливает сервер по порту `5055` и уведомляет о выключении.

4. **Ручной запуск из терминала:**
   ```bash
   source venv/bin/activate
   python3 app.py
   ```
   После запуска откройте в браузере адрес **`http://127.0.0`**.

## Структура проекта

* `app.py` — основной сервер Flask, API, OCR-обработка и HTML-шаблон интерфейса.
* `static/main.js` — клиентская логика таблиц, подсветки цен, сквозного выделения строк, редактирования, канбан-доски, реестра приёмки и архива.
* `toggle_zakupki.sh` — скрипт включения и выключения сервера одной кнопкой по порту `5055`.
* `zakupki.db` — локальная база данных SQLite (создаётся автоматически, исключена из Git).
* `backups/` — папка автоматических и ручных резервных копий базы и архивов программы (исключена из Git).
* `debug.log` / `server.log` — журналы работы приложения и диагностики (исключены из Git).
