# Система управления закупками по проектам

Локальное веб-приложение на Python (Flask + SQLite) для ведения полного цикла закупок предприятия: от формирования заявки по проекту и сравнения счетов поставщиков до контроля оплаты, отслеживания доставки на канбан-доске и фиксации приёмки товара.

Приложение работает полностью автономно на локальном компьютере без облачных серверов и платных подписок, а все базы данных и файлы счетов хранятся локально на диске.

## Основные возможности

1. **Проекты и сравнение счетов (Вкладка 1):**
   * Создание проектов с привязкой к любой выбранной папке на диске (через системное диалоговое окно).
   * Формирование списка закупаемых позиций в метрах.
   * Загрузка счетов поставщиков (PDF, Excel `.xlsx`/`.xlsm`, сканы/изображения) с автоматическим сохранением оригиналов файлов в папку проекта.
   * Автоматическое извлечение текстового слоя из PDF и таблиц Excel для удобного переноса цен (с предупреждением, если загружен скан без текста).
   * Встроенный калькулятор НДС (+20% / +22%) для быстрого пересчёта цен, указанных без налога.
   * Двойной учёт единиц измерения в таблице сравнения: ввод веса из счёта (кг) и добавление длины (м).
   * Отдельные строки для фиксации **стоимости доставки до терминала** и **примечаний** (ГОСТ, страна происхождения, сроки отгрузки).
   * Выбор выгодных позиций у одного или нескольких поставщиков и передача их в работу.

2. **Канбан-доска отслеживания (Вкладка 2):**
   * Визуальный контроль выбранных позиций по этапам: *Передано в бухгалтерию* → *Оплачено / Ждём отгрузку* → *В пути* → *Прибыло / На приёмке*.
   * Перетаскивание карточек мышкой между колонками.
   * Учёт логистики в каждой карточке: транспортная компания (ТК), трек-номер и плановая дата прибытия (просроченные заказы автоматически подсвечиваются красной рамкой).
   * Открытие прикреплённого файла счёта в один клик.

3. **Реестр полученных товаров (Вкладка 3):**
   * Фиксация приёмки товара с выбором одного из **7 цветов** маркировки.
   * Единая таблица всех закрытых позиций с возможностью изменить цветовую отметку (синхронизируется с таблицей проекта).

## Технологии

* **Backend:** Python 3, Flask, SQLite3
* **Парсинг документов:** `pdfplumber`, `openpyxl`
* **Системные диалоги:** `tkinter`
* **Frontend:** HTML5, CSS3, Vanilla JavaScript (без внешних зависимостей)

## Установка и запуск (Linux)

1. Установите системный пакет для диалоговых окон (если не установлен):
   ```bash
   sudo apt install python3-tk
   ```

2. Создайте виртуальное окружение и установите зависимости:
   ```bash
   python3 -m venv venv
   source venv/bin/activate
   pip install flask pdfplumber openpyxl
   ```

3. Запустите приложение:
   ```bash
   python3 app.py
   ```
   Сервер запустится по адресу `http://127.0.0` и автоматически откроет вкладку в браузере (Opera или Google Chrome).

## Структура данных

* `app.py` — основной файл сервера и веб-интерфейса.
* `zakupki.db` — локальная база данных SQLite (создаётся автоматически при первом запуске).
* Файлы счетов сохраняются напрямую в директории, указанные при создании соответствующих проектов.
