# Система управления закупками по проектам (`zakupki-kanban`)

Локальное веб-приложение на Python (Flask + SQLite) для ведения полного цикла закупок предприятия: от формирования заявки по проекту и сравнения счетов поставщиков до контроля оплаты, отслеживания доставки на канбан-доске и фиксации приёмки товара.

Приложение работает полностью автономно на локальном компьютере без облачных серверов и платных подписок, а все базы данных, резервные копии и оригиналы счетов хранятся локально на диске.

## Основные возможности

1. **Проекты и сравнение счетов (Вкладка 1):**
   * **Реестр проектов:** список всех проектов в левой панели с датой создания и живыми индикаторами прогресса (*На оплату*, *Оплачено*, *В пути*, *Получено*).
   * **Привязка к папкам:** выбор любой рабочей директории на диске через системное диалоговое окно (`zenity`) и отображение списка всех прикреплённых файлов проекта прямо под его заголовком с открытием в один клик.
   * **Импорт готовых таблиц сравнения:** загрузка уже существующих сводных таблиц в любых форматах (**`.xlsx`**, **`.xlsm`**, **`.xls`**, **`.ods`**) с автоматическим извлечением цен (включая очистку от ГОСТов и диаметров), примечаний и автоматической привязкой файлов счетов из папки проекта к столбцам поставщиков.
   * **Работа со счетами поставщиков:** загрузка PDF, Excel (`.xlsx`, `.xlsm`, `.xls`), LibreOffice Calc (`.ods`) и сканов с сохранением оригиналов в папку проекта. Автоматическое извлечение текстового слоя и автопоиск стоимости услуг резки/раскроя и доставки.
   * **Встроенный калькулятор НДС (+20% / +22%):** быстрый пересчёт цен, указанных без налога.
   * **Умная цветовая подсветка цен в таблице:**
     * **Светло-зелёный** — лучшая (минимальная) общая цена за позицию.
     * **Светло-голубой** — позиция дороже минимальной (например, отгрузка целым хлыстом), но выгоднее в пересчёте за **1 метр** или **1 кг**.
     * **Светло-розовый** — самая высокая цена среди предложений.
   * **Гибкий выбор и удобная навигация:** закреплённый первый столбец материалов, закреплённая шапка поставщиков, постоянный горизонтальный бегунок, выбор отдельных позиций или **всего счёта целиком** одной кнопкой в шапке столбца.

2. **Канбан-доска отслеживания счетов (Вкладка 2):**
   * **Группировка по проектам и счетам:** вместо громоздкого списка отдельных позиций каждая карточка представляет конкретный счёт в рамках проекта с указанием поставщика, количества позиций и общей суммы.
   * **Этапы движения:** перетаскивание карточек мышкой между колонками: *Передано в бухгалтерию* → *Оплачено / Ждём отгрузку* → *В пути* → *Прибыло / На приёмке*.
   * **Логистика и контроль сроков:** учёт транспортной компании (ТК), трек-номера и плановой даты прибытия на весь счёт (просроченные поставки автоматически выделяются красной рамкой).
   * **Приёмка в один клик:** открытие файла счёта прямо из карточки и перевод всего счёта в полученные с выбором одного из **7 цветов** маркировки.

3. **Реестр полученных товаров (Вкладка 3):**
   * **Двухуровневый просмотр:** в левой колонке отображается список всех полученных проектов и счетов (окрашенных цветом приёмки), а в правой области при клике раскрывается подробный состав принятых позиций с весом, метрами и ценой.
   * **Гибкая цветовая маркировка:** возможность изменить цвет как для всего полученного счёта целиком, так и для каждой отдельной позиции (синхронизируется с основной таблицей проекта).

4. **Надёжность и резервное копирование:**
   * Автоматическое создание резервных копий базы данных (`backups/`) при каждом запуске приложения (хранятся последние 30 копий).
   * Кнопка **«💾 Резервная копия»** в верхней панели для ручного сохранения снимка базы в любой момент.
   * Подробное логирование событий сервера и клиентских ошибок в `debug.log`.

## Технологии

* **Backend:** Python 3, Flask, SQLite3
* **Парсинг документов и таблиц:** `pdfplumber`, `openpyxl`, `xlrd`, `odfpy`
* **Системные диалоги и уведомления (Linux):** `zenity`
* **Frontend:** HTML5, CSS3, Vanilla JavaScript (вынесен в `static/main.js`, без внешних фреймворков)

## Установка и запуск (Linux Mint / Ubuntu)

1. Установите системный пакет для диалоговых окон (если не установлен):
   ```bash
   sudo apt install zenity
   ```

2. Создайте виртуальное окружение и установите зависимости:
   ```bash
   python3 -m venv venv
   source venv/bin/activate
   pip install flask pdfplumber openpyxl xlrd odfpy
   ```

3. **Запуск через скрипт-переключатель (рекомендуется):**
   Используйте скрипт `toggle_zakupki.sh` (или ярлык на рабочем столе):
   * Первый запуск включает сервер в фоне и выводит системное окно-индикатор с адресом **`http://127.0.0`**.
   * Повторный запуск останавливает сервер по порту `5055` и уведомляет о выключении.

4. **Ручной запуск из терминала:**
   ```bash
   source venv/bin/activate
   python3 app.py
   ```
   После запуска откройте в браузере адрес **`http://127.0.0`**.

## Структура проекта

* `app.py` — основной сервер Flask, API и HTML-шаблон интерфейса.
* `static/main.js` — клиентская логика таблиц, подсветки цен, канбан-доски и реестра приёмки.
* `toggle_zakupki.sh` — скрипт включения и выключения сервера одной кнопкой с индикацией статуса.
* `zakupki.db` — локальная база данных SQLite (создаётся автоматически, исключена из Git).
* `backups/` — папка автоматических и ручных резервных копий базы данных (исключена из Git).
* `debug.log` / `server.log` — журналы работы приложения и диагностики (исключены из Git).
